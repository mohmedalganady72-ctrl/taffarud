## أجزاء مؤقتة وليست مكتملة

- صفحات المصمم والحساب والطلبات والإدارة تعرض حاليًا شاشة «قيد التجهيز».
- نقاط API موجودة كمسارات صالحة، لكنها تعيد `501 Not Implemented` حتى تنفيذ منطق الخادم.
- بيانات منتجات المتجر وصورها تقرأ من Supabase، بينما أقسام الصفحة الرئيسية ما زالت تستخدم بيانات عرض محلية.
- تسجيل الدخول وإنشاء الحساب غير مربوطين بـ Firebase بعد.
- أزرار الهيرو والتنقل تعمل كرابط للمسارات، لكن وظائف المسارات المستهدفة لم تُنفذ بعد.
- خط «ثمانية» غير مستخدم حاليًا إلى أن يتم تأكيد ترخيص استخدامه على الويب؛ تُستخدم خطوط عربية بديلة.
