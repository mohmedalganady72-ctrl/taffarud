# دليل التصميم والأسلوب — «تَفرّد»

الهدف: موقع **فاخر هادئ** ينقل الإحساس بالجلد الفاخر والحرفة اليدوية: مساحات واسعة، ألوان دافئة، خط عربي أنيق، وحركة ناعمة لا تُشتّت عن المنتج.

---

## 1. شخصية التصميم

| المبدأ | معناه عملياً |
|---|---|
| **فخامة هادئة** | خلفيات عاجية دافئة، لمسات ذهبية قليلة، بدون ألوان صارخة |
| **مساحة بيضاء سخية** | المنتج بطل الصفحة، والفراغ جزء من التصميم |
| **حرفية وتفاصيل** | حدود رفيعة، ظلال ناعمة، صور مقرّبة للخامات |
| **بساطة وضوح** | خطوات التصميم واضحة، وكل شاشة لها قرار واحد |
| **هوية عربية معاصرة** | خط ثمانية، واتجاه RTL أصيل، وزخرفة سدو خفيفة اختيارية |

**نبرة الكلام:** دافئة، قصيرة، راقية. أمثلة: «صمّم شنطتك بيدك»، «تفرّد بتفاصيلك»، «أنشئ التصميم»، «نُجهّز تصميمك».

## 2. الخط: ثمانية

الخط المطلوب هو **خط ثمانية** (Thmanyah)، وهو مجاني للتحميل من الصفحة الرسمية: `ask.thmanyah.com` (ابحث عن «خط ثمانية»).

### توزيع الاستخدام
| الاستخدام | العائلة |
|---|---|
| العناوين الكبيرة والشعار النصي والأرقام الضخمة | **Thmanyah Serif Display** |
| واجهة الموقع (أزرار، قوائم، حقول، أسعار) | **Thmanyah Sans** |
| النصوص الطويلة (من نحن، السياسات) | **Thmanyah Serif Text** أو Sans |

> أسماء العائلات أعلاه كما وجدتها في موقع يستضيفها. تحقق من الأسماء والأوزان الفعلية داخل الحزمة بعد التحميل، وعدّل ملف CSS بحسبها.

### تنبيهات الترخيص (راجعها قبل الإطلاق)
- الخط متاح **بصيغة OTF فقط** حالياً، والصفحة الرسمية تذكر أنه مخصص لأجهزة Windows وmacOS.
- الترخيص **يمنع تعديل ملفات الخط أو إعادة تسميتها أو الاشتقاق منها**، ويمنع استخدام اسم «ثمانية» أو هويتها بما يوحي بشراكة أو تزكية.
- استخدامه على الويب عبر `@font-face` وتحويل OTF إلى WOFF2 والاستخدام التجاري: **لم أجد نصاً رسمياً صريحاً يحسمها**. راسل **font@thmanyah.com** واطلب تأكيداً مكتوباً قبل الإطلاق.
- لا تكتب «بخط ثمانية» كشعار في موقعك.

### خطوط احتياطية
Cairo → Tajawal → system-ui. وللتطريز على الشنطة (يُرسم من الخادم فوق الصورة) استخدم **Cairo وTajawal** وخطوطاً زخرفية من Google Fonts لأنها مفتوحة الترخيص.

### التحميل
```css
@font-face {
  font-family: "Thmanyah Sans";
  src: url("/fonts/thmanyah/sans-regular.woff2") format("woff2");
  font-weight: 400; font-style: normal; font-display: swap;
}
@font-face {
  font-family: "Thmanyah Sans";
  src: url("/fonts/thmanyah/sans-medium.woff2") format("woff2");
  font-weight: 500; font-style: normal; font-display: swap;
}
@font-face {
  font-family: "Thmanyah Serif Display";
  src: url("/fonts/thmanyah/serif-display-regular.woff2") format("woff2");
  font-weight: 400; font-style: normal; font-display: swap;
}
/* أضف بقية الأوزان المتاحة في الحزمة بنفس الطريقة */
```

### مقاسات الخط
| الاسم | المقاس (جوال ← حاسوب) | ارتفاع السطر | العائلة |
|---|---|---|---|
| Display | `clamp(2.5rem, 6vw, 4.5rem)` | 1.2 | Serif Display |
| H1 | `clamp(2rem, 4.5vw, 3.25rem)` | 1.25 | Serif Display |
| H2 | `clamp(1.5rem, 3vw, 2.25rem)` | 1.35 | Serif Display |
| H3 | `1.25rem` | 1.45 | Sans، وزن 500 |
| Body L | `1.125rem` | 1.85 | Sans |
| Body | `1rem` | 1.75 | Sans |
| Small | `0.875rem` | 1.6 | Sans |
| Caption | `0.75rem` | 1.5 | Sans |

**قواعد الخط العربي**
- **لا `letter-spacing` أبداً** (يكسر اتصال الحروف).
- ارتفاع السطر أكبر من اللاتيني (1.75 للنص).
- الأرقام **غربية (0-9)** للأسعار، مع `font-variant-numeric: tabular-nums` لتثبيت عرضها.
- الحد الأدنى لنص الجوال 16px، وللنص الثانوي 14px.

## 3. الألوان

لوحة دافئة: **عاجي + إسبرسو + شمبانيا ذهبي**، مع أخضر غابات عميق كلون ثانوي.

| Stone 600 | `#6B5F57` | النص الثانوي |
| **Espresso 900** | `#2A211C` | النص الرئيسي والأزرار الأساسية |
| Gold 300 | `#E4D2AE` | خلفيات لمسات ذهبية خفيفة |

**حالات**
| الحالة | القيمة |
|---|---|

## 5. أسلوب العرض

- **المنتج أولاً:** صور كبيرة نظيفة، نص قليل، وعناوين بخط Display.
- **تخطيط تحريري (Editorial):** صورة كبيرة بجانب نص قصير، مع تبديل الجهة بين الأقسام.
- **شبكة المنتجات:** عمودان في الجوال، 3 في التابلت، 4 في الحاسوب. فجوة 16 / 24 / 32.
- **نسب الصور:** المنتج `4:5`، صفحة المُصمِّم `1:1`، **صورة النتيجة (أمام وخلف) `2:1`**.
- **الصور:** WebP/AVIF عبر `next/image`، مع Blur Placeholder وخلفية `--sand-200` أثناء التحميل.
- **التصوير:** إضاءة ناعمة طبيعية، خلفية عاجية/رملية موحّدة، الشنطة في المنتصف، ولقطات مقرّبة للخامات.
- **زخرفة السدو (اختيارية):** نمط هندسي بلون Gold 500 وشفافية 6-8% كفاصل أو خلفية خفيفة، دون مبالغة.
- **الأيقونات:** Lucide، خط `1.5px`، مقاس 20/24.

### أقسام الصفحة الرئيسية
1. **Hero:** عنوان Display + جملة واحدة + زرّان («صمّم شنطتك»، «تسوّق الجاهز») + صورة كبيرة
2. **كيف تعمل؟** ثلاث خطوات: اختر، خصّص، استلم
3. **الأنواع الثلاثة:** شنطة يد، توت باق، باوتش (بطاقات كبيرة)
4. **الجاهز المميّز:** شبكة منتجات
5. **الخامات:** جلد نباتي، قطن عضوي، سدو (لقطات مقرّبة)
6. **أمثلة تصاميم الآخرين**
7. **أسئلة شائعة + تذييل**

## 7. صفحة «صمّم شنطتك»

**الجوال**
- أعلى الشاشة: صورة الشنطة البيضاء الأساسية (1:1) بخلفية `--sand-200`.
- تحتها: المراحل، ثم خيارات المرحلة الحالية.
- أسفل الشاشة: شريط السعر مع زر «أنشئ التصميم».
- **الملخص:** شرائح (Chips) صغيرة تعرض اختيارات العميل أسفل الصورة.

**الحاسوب**
- عمودان: الصورة ثابتة (Sticky) في جهة، والخيارات في الجهة الأخرى.
- السعر في أسفل عمود الخيارات.

**أثناء التوليد**
- الصورة تتحول إلى هيكل تحميل (Shimmer) ذهبي ناعم.
- رسائل تتبدل كل 3 ثوانٍ: «نختار الخامة...»، «نضبط اللون...»، «نضع اللمسات الأخيرة...».
- تعطيل الأزرار ومنع النقر المكرر.

**النتيجة**
- ظهور الصورة 2:1 بتلاشي وتكبير خفيف (`scale .98 → 1`).
- تحتها المواصفات والسعر الشامل وأزرار: «ادفع»، «أعد التوليد (متبقٍ 2)»، «عدّل الاختيارات».
- ملاحظة صغيرة: «الصورة تقريبية، والمنتج النهائي قد يختلف قليلاً».

## 8. الحركة والانتقالات

### المبادئ
- **ناعمة وبطيئة نسبياً:** الفخامة في الهدوء، لا في الاستعراض.
- الحركة تخدم المعنى (تأكيد، توجيه، انتقال)، ولا تزيّن فقط.
- **لا ترتد (Bounce) ولا تهتز**، فهذا لا يناسب الفخامة.

### القيم
```css
--ease-out: cubic-bezier(.22, 1, .36, 1);    /* الدخول */
--ease-in-out: cubic-bezier(.65, 0, .35, 1); /* التحويل */
--dur-micro: 120ms;  /* ضغط، تحويم */
--dur-fast: 200ms;   /* ألوان، حدود */
--dur-base: 320ms;   /* ظهور عناصر */
--dur-slow: 500ms;   /* أقسام، صور */
--dur-hero: 800ms;   /* الهيرو */
```

### الحركات المعتمدة
| الموضع | الحركة |
|---|---|
| **ظهور الأقسام عند التمرير** | تلاشٍ + صعود 16px، `--dur-slow`، تأخير متتالٍ 60ms بين العناصر |
| **الهيرو** | العنوان يظهر كلمة كلمة (تأخير 40ms)، ثم الصورة بتكبير `1.05 → 1` خلال 800ms |
| **بطاقة المنتج (Hover)** | رفع 4px + ظل أكبر + تكبير الصورة 1.04 (`--dur-slow`) |
| **الأزرار** | Hover: تحوّل اللون 200ms. الضغط: `scale(.98)` خلال 120ms |
| **الانتقال بين الصفحات** | تلاشٍ 200ms + إزاحة 8px للمحتوى |
| **عيّنات اللون/الخامة** | الحلقة الذهبية تظهر بتكبير من 0.8 خلال 200ms |
| **السعر** | الرقم يتغير بعدّ تصاعدي/تنازلي سلس 300ms |
| **المراحل** | خط التقدم يمتلئ بالذهبي خلال 320ms |
| **النافذة السفلية** | تنزلق من الأسفل 320ms مع تعتيم الخلفية |
| **التحميل** | Shimmer: تدرج رملي/عاجي يتحرك 1.6 ثانية بتكرار |
| **حالة الطلب الحالية** | نبض ذهبي هادئ: `scale 1 → 1.4` وتلاشي، كل 2 ثانية |
| **الإشعارات** | تصعد 12px مع تلاشٍ وتختفي بعد 3 ثوانٍ |

```css
@keyframes fade-up {
  from { opacity: 0; transform: translateY(16px); }
  to   { opacity: 1; transform: translateY(0); }
}
@keyframes shimmer {
  from { background-position: 200% 0; }
  to   { background-position: -200% 0; }
}
.skeleton {
  background: linear-gradient(90deg, var(--sand-200) 25%, var(--ivory-50) 50%, var(--sand-200) 75%);
  background-size: 200% 100%;
  animation: shimmer 1.6s linear infinite;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }
}
```

### التنفيذ
- **CSS** للحركات الصغيرة (Hover، الأزرار، Shimmer).
- **Framer Motion (حزمة `motion`)** للظهور عند التمرير وانتقالات الصفحات وعدّاد السعر.
- **لا تستخدم** تمريراً مخصصاً (Smooth Scroll Hijacking)، فهو يتعارض مع RTL ويضر بأداء الجوال.
- احترم دائماً `prefers-reduced-motion`.

## 9. إمكانية الوصول والأداء

- أهداف اللمس **44×44px على الأقل**.
- حلقة التركيز: `outline: 2px solid var(--gold-700); outline-offset: 3px`.
- كل صورة لها `alt` عربي واضح (مثل «شنطة يد جلد نباتي بيج»).
- لا تعتمد على اللون وحده لإظهار الحالة؛ أضف نصاً أو أيقونة.
- الأداء: خطوط `font-display: swap`، صور مُحسَّنة، `loading="lazy"` تحت الشاشة الأولى، والحركة بـ `transform` و`opacity` فقط.

## 10. لوحة المدير

- نفس الرموز (Tokens) لكن بكثافة أعلى: جداول مضغوطة، 14px، بدون حركة زخرفية.
- شريط جانبي في جهة اليمين (RTL)، خلفية Espresso ونص عاجي، والعنصر النشط بخط ذهبي.
- الجداول: ترويسة `--sand-200`، صفوف بحدود رفيعة، وشارات الحالة المذكورة أعلاه.
- الصفحات: الطلبات، تفاصيل الطلب، المنتجات الجاهزة، الموديلات الأساسية، الخيارات والأسعار.
