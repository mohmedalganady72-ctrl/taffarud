# تَفرّد

متجر عربي RTL للحقائب الجاهزة والمخصصة، مبني بـ Next.js وTailwind.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## الأوامر

- `npm run dev` — بيئة التطوير
- `npm run typecheck` — فحص TypeScript
- `npm run build` — بناء الإنتاج

صور الصفحة الرئيسية مولّدة خصيصًا للمشروع ومحفوظة في `public/images/home`.
